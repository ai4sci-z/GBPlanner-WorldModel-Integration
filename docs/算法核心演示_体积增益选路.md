# 算法核心演示:体积增益选路(可运行,对应 mentor md)

> 📌 **2026-07-03 校核**:本文内容仍有效。项目最新全景与"你在这里"路线图见 [README](../README.md);运行时排坑最新进展见 [运行时排错记录_humble.md](运行时排错记录_humble.md)。

> 这是**今天唯一真正跑通、你能亲手复现**的成果。纯 C++,零基础设施依赖。直接演示 mentor md 的核心:
> **"在机器人附近采样候选方向 → 用光线投射算每条能看见多少未知空间(体积增益)→ 减距离/转向惩罚 → 选最高的。"** 最后更新 2026-06-30。

## 二、可视化结果(组会可直接展示)
![GBPlanner 核心决策:对每个方向算体积增益,选最高且避障的方向](../images/gain_decision.png)
- 蓝点=机器人;深灰=墙;浅绿=已探索;灰=未知;绿圈大小=各方向体积增益;**红线+黄点=被选中的方向**。

## 四、它证明了什么(报告论点)
1. **算法真的在"看哪里没探过"**:朝开口(未知多)的方向增益 0.420,朝墙的方向只有 0.158——增益随"能看见的未知量"明确变化。
2. **会避障 + 偏好少绕路/少转头**:候选只取已知空闲点(避障);评分含距离/转向惩罚。
3. **这正是 mentor md 的"自主探索决策":输入地图+位姿 → 输出目标(航点)。**
