## 三、实打实的成果(可当场验证,非空口)

1. **✅ 官方 GBPlanner 仿真在本机跑通并量化**(预研B):无人机起飞→3D 建图→图搜索选路→自主巡飞→时间预算到自动返航。**实测:飞行 291.3m、3D 地图 132,091 体素、自动返航、地图落盘 4MB**(曲线 `images/exploration_metrics_full.png`)。两条命令可复现([实操手册](docs/实跑操作手册_图文版.md))。

2. **✅ 论证了 frontier_lite 的本质缺陷**(代码铁证):它不订阅任何地图、按计时器循环 3 个写死动作,`source` 字段自承 `bounded_lite_pattern`——**不是探索算法**。GBPlanner 的精确插入点已锁定。

3. **✅ world-model 平台在本机基本复现 + 修了 13 个真 bug**(预研A):9/9 镜像构建成功;35 轮受控实验逐个剥掉 humble 迁移的 13 个坑(总根因=机器人根本没生成、编排真凶=容器身份致 gz 发现瘫痪…),把平台从"机器人不存在"推进到"感知全通→SLAM 闭环→位姿回灌飞控"。全过程有完整证据链([战役实录](docs/预研A排错战役实录_35轮实验全解.md))。

4. **✅ 真版桥接=B2.5 自写薄桥,数据链全线贯通**(官方 ros1_bridge/zenoh 实验判死):transport 三段通→GBPlanner/voxblox 真消费 world-model 输入(真 odom 604 条+真 3D 点云 115 帧→**voxblox 3D 体素地图 90,472 点 zspan 13.2m**)→trajectory 回流→**FCU 消费直证**(/ap/v1/cmd_vel 出现与适配器逐位吻合的 GBP-SIGNATURE)。另有 `gbplanner_gain` 2D 原型(历史素材)。

5. **✅ 算法核心可运行 + 论文对应**:纯 C++ 体积增益决策 demo(30秒复现);读了原始论文校准了理解、写了[论文↔代码对应关系](docs/GBPlanner原始论文与代码对应关系.md)。
