## 0. 先建立一个认知(很重要,否则会一直找不到"入口")
机器人仿真软件(Gazebo、RViz)**不像 QQ/微信那样有桌面图标**。它们的特点:
- 跑在 **WSL2 里的 Docker 容器**中(相当于 Windows 里的一个 Linux 小系统 + 集装箱);
- 用**命令**启动;启动后**会在你 Windows 桌面弹出窗口**(靠 WSLg 技术),或在**网页查看器**里看;
- 所以"入口" = 打开一个终端,敲一条命令。下面命令我都给你。

## 2. 怎么检查"Claude 到底干了什么"(命令 → 你应看到)
在上面的 Ubuntu 终端里敲:

| 你想确认 | 敲这个命令 | 你应该看到 |
|---|---|---|
| Ubuntu 装好了 | `lsb_release -a` | `Ubuntu 22.04` |
| Docker 装好了 | `docker ps` | 一行表头,无报错 |
| **已复现哪些环境(镜像)** | `docker images` | `gbplanner-ref`、`navlab/ros-base`、`navlab/ardupilot-sitl` 等 |
| **world-model 构建进度** | `tail -n 20 ~/navlab_build.log` | 正在构建哪个镜像的日志 |
| **核对 9 个镜像是否齐全** | `docker images \| grep navlab.*humble` | 应有 9 个 navlab/*:humble(差几个=还没建完/失败) |
| GBPlanner 核心代码测试 | `cd /mnt/c/CCproject/GBPlanner-WorldModel-Integration/code/gbplanner_core && cmake -S . -B build >/dev/null && cmake --build build >/dev/null && ctest --test-dir build` | `100% tests passed` |

> 这些命令的输出,就是"我真干了活"的实据,组会可直接展示。
>
> ✅ **已实测(2026-06-29)**:`ai4s` 账号可正常用 docker;`ctest` 输出 `100% tests passed`。这两条照敲即可。

## 3. 怎么【亲眼看到 GBPlanner 仿真】(预研B,镜像已就绪,现在就能看)
GBPlanner 的官方仿真镜像 `gbplanner-ref` 已经建好。运行它:
```bash
# 把参考环境拷到 WSL(只需一次)
cp -r /mnt/c/CCproject/GBPlanner-WorldModel-Integration/runbooks/gbplanner_ref ~/gbplanner_ref
cd ~/gbplanner_ref
bash build_and_run.sh          # 镜像已存在,会直接启动 rmf_sim
```
**你应该看到**:几十秒后,**Windows 桌面弹出两个窗口**——
- **Gazebo**:一个 3D 世界,里面一架无人机;
- **RViz**:无人机边飞边建的 3D 点云地图 + GBPlanner 画出的探索图和目标航点。

这就是"进入仿真软件看实例"。截图:按 `Win+Shift+S` 框选,或告诉我我帮你存到 `images/`。
> 注:GUI 在容器里软件渲染,启动稍慢;若卡,等 world-model 构建完(释放 CPU)再跑更流畅。
>
> ⚠️ **诚实标注**:此 GUI 弹窗我**尚未亲自验证**(怕你照敲弹不出来出丑)。我会在 world-model 构建完成后**亲自跑一遍 + 截图**,确认弹窗正常、并把准确命令/截图补进本节,再请你照做。在我验证前,这条先别在组会上现场演示。

## 4. 怎么看 world-model 仿真(预研A,**构建完成后**)
先确认构建完成:`docker images` 里出现全部 `navlab/*`(ros-base/ardupilot-sitl/gazebo-headless/fast-lio/slam-cartographer/gazebo-sensor/official-baseline/companion)。然后:
```bash
cd ~/ws/world-model
go run ./cmd/navlab-sim run exploration      # 跑"探索"任务
```
**你应该看到**:Gazebo 里无人机在迷宫里飞、Cartographer 画 2D 地图、frontier_lite 驱动它去几个目标点。
- 还可用 **Foxglove**(网页版机器人可视化,类似"仿真播放器")看回放:`go run ./cmd/navlab-sim foxglove ...`(待我跑通后在本手册补精确命令 + 截图)。
