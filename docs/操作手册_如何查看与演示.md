## 一、认知科普(新手必读)

机器人仿真软件(Gazebo、RViz)**不像 QQ/微信那样有桌面图标**:
- 它们跑在 **WSL2 里的 Docker 容器**中(Windows 里的 Linux 小系统 + 集装箱);
- 用**命令**(或做好的 `.bat`)启动;启动后**窗口弹到 Windows 桌面**(靠 WSLg);
- 所以"入口"不是图标,而是一条命令/一个 bat——这就是 `launchers/` 存在的意义。
