# 对比实验与缺陷论证设计(任务 #5 + #6)

> 目的:① **用实据论证 frontier_lite 不足**(不空口);② **GBPlanner vs frontier_lite 量化对比,突出优势**。
> 所有参数引真实源码;待实测的数字等 exploration 跑通后填入。最后更新 2026-06-29。

## 1. frontier_lite 的真实样貌(已从源码确证)
| 项 | 值 | 出处 |
|---|---|---|
| 策略 | `frontier_lite`(P8 文档原话:"bounded frontier-lite / corridor probing"最小探索闭环) | exploration.yaml:20 / P8设计 |
| 探索窗口 | **仅 26 秒** | exploration.yaml:21 |
| 速度 | **0.10 m/s**(极慢) | exploration.yaml:22 |
| 通过门槛 | 凑 **≥3 个目标点**、路径 ≥0.35m | exploration.yaml:23-24 |
| 用的传感器/地图 | **2D** `/scan` + Cartographer **2D** `/map` | P8设计 §3 / model.sdf |
| 明确不做 | 不是完整 Nav2;不覆盖全部可达空间 | P8设计 §3 |

→ **缺陷论点(有据)**:frontier_lite 只是个"证明流水线通了"的 **2D 占位探索**,**只在平面上凑几个点**,既不立体、也不追求探索效率/覆盖最大化。
