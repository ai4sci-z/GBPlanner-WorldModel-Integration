## §0 前置环境 + 一条铁律(上次失败的元凶)

**前置环境**(都已配好,只需确认):Win11 + WSL2(Ubuntu-22.04,用户 ai4s)+ Docker(WSL 内)+ 镜像 `gbplanner-ref`。

> ### ⚠️ 铁律:先开一个"看门窗口",全程别关!
> WSL 有省电机制:**里面没有任何终端开着时,十几秒后整个 Linux 自动关机**,里面的 Docker 和仿真容器会**全部无征兆死掉**(退出码 255)。上次组会跑不起来,最大嫌疑就是它。
> **做法**:开始前,开一个 Ubuntu 窗口(开始菜单搜 `Ubuntu` 回车),**放着不动、不要关**。它就是看门的。

### 步骤 0.1 开"看门窗口"
开始菜单 → 输入 `Ubuntu` → 回车。看到 `ai4s@AI4S:~$` 即可,放着别关。

### 步骤 0.2 再开一个 Ubuntu 窗口作为"操作窗口",确认环境
```bash
docker images | grep gbplanner
```
**你会看到**(有这一行就绪;没有则找我重建镜像):
```
gbplanner-ref   latest   ...   10.7GB
```

## §1 主演示:GBPlanner 自主探索全过程(两条命令)

### 步骤 1.1 启动仿真(Gazebo 后台 + RViz 弹窗)
在**操作窗口**里执行:
```bash
bash /mnt/c/CCproject/GBPlanner-WorldModel-Integration/runbooks/gbplanner_ref/run_light.sh
```
**你会看到**:终端打印"已启动";**约 20~30 秒后,Windows 桌面弹出 RViz 窗口**(深灰界面,左侧 Displays 面板,左下角有 GbPlanner Control 按钮组,底部状态条显示 fps)。
- 弹出个"ROS 1 End-of-Life"小提示框 → 点 OK 关掉即可(无害)。
- 再等约 30 秒,RViz 中央会出现**点云轮廓**(box 迷宫的墙,勾选左侧 `Sensors` 更明显)和一个**三色小坐标轴**(无人机,还趴在地上)。

### 步骤 1.2 起飞并触发自主探索
等 RViz 出现后(建议再等 30 秒让建图起步),执行:
```bash
bash /mnt/c/CCproject/GBPlanner-WorldModel-Integration/runbooks/gbplanner_ref/takeoff_and_explore.sh
```
**你会看到**(终端按步骤打印,总耗时约 40 秒):
```
===== 0. 起飞前高度 =====      z: 0.056...(趴地上)
===== 1. 向 lee 控制器发升高位姿(z=1.2) =====
===== 2. 等 8 秒,看高度 =====   z: 1.20...(飞起来了!)
===== 3. 触发自主探索 =====     success: True
===== 4. 10 秒后 =====          当前位置 x/y 已明显变化(它自己飞走了)
```
**同时在 RViz 里**:三色轴升空移动;紫球+橙线(候选路网)一片片刷出;**绿色粗线**(本轮最优路径)不停变化;粉线(已飞轨迹)越拖越长;红球(边界)不断向外推进。**这就是体积增益探索的现场直播**——具体每个元素的含义看[详解文档](体积增益与RViz界面详解.md)。

**它会一直自己飞约 7 分钟**(时间预算 480 秒,t≈435s 时终端所在的仿真会打出 `HOMING ENGAGED`),然后**自动返航**到起点悬停——整个任务周期无须任何操作。

### 步骤 1.3(可选)现场互动
RViz 左下 **GbPlanner Control** 面板可以点:`Stop Planner` 暂停探索、`Start Planner` 继续、`Go Home` 手动召回。玩坏了不要紧,重跑步骤 1.1 即可。

### 步骤 1.4 结束/重来
```bash
docker rm -f gbplanner_ref
```
**你会看到**:打印 `gbplanner_ref`,RViz 窗口关闭。想再演示,回到步骤 1.1。

## §5 故障排查表(先查这里再找我)

| 症状 | 原因 | 处置 |
|---|---|---|
| 跑着跑着容器全没了/RViz 消失 | **看门窗口没开或被关了**(WSL 空闲关机) | §0 铁律;重开看门窗口后从步骤 1.1 重来 |
| RViz 没弹出 | WSLg 通路问题 | 操作窗口执行 `echo $DISPLAY`,应输出 `:0`;为空则重启 WSL:PowerShell `wsl --shutdown` 后重开两个窗口 |
| 步骤 1.1 报 `No such image` | 镜像缺失 | `docker images | grep gbplanner` 确认;缺失找我重建(约 20 分钟) |
| 步骤 1.2 打印 z 还是 0.05 | 仿真还没就绪就触发了 | 等 30 秒重新执行步骤 1.2(可重复执行,无副作用) |
| RViz 很卡 | 软件渲染+后台占 CPU | 关闭其他重负载;演示不影响正确性 |
| 报 `Cannot connect to the Docker daemon` | docker 服务未起(常伴随 WSL 刚被关过) | 看门窗口执行 `sudo service docker start` 或直接重启 WSL 后重来 |
