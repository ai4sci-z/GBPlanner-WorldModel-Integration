## 0. 先有个概念:启动后你会看到什么
跑起来后,**Windows 桌面会弹出两个窗口**:左边 **Gazebo**(3D 虚拟世界),右边 **RViz**(算法可视化)。长这样(示意):

![预期画面示意](images/tut_screen.png)

- **Gazebo**:虚拟世界 + 无人机在迷宫里飞(物理仿真)。
- **RViz**:无人机"脑子"里的地图——蓝色=已探索,绿线=规划路径,黄点=下一个目标。**看着地图一点点被探开**,就是探索算法在工作。

## 1. 第一步:打开 Linux 终端
开始菜单搜 **Ubuntu**(或 **wsl**)→ 回车。出现 `ai4s@AI4S:~$` 就进来了。
> 这就是我一直操作的环境;所有命令都在这里敲。

## 2. 第二步:确认镜像齐了
```bash
docker images | grep navlab
```
- 看 **GBPlanner(路线A)**:只要有 `gbplanner-ref` 就行(已就绪)。
- 看 **world-model(路线B)**:要数到 **9 个** `navlab/*:humble`(还差 official-baseline 在建)。

## 5. 怎么截图存档(组会要用)
- 全屏/框选:按 **`Win + Shift + S`** → 框住 Gazebo/RViz 窗口 → 自动进剪贴板 → 粘到任意地方保存。
- 或直接告诉我"帮我截图",我把图存到项目 `images/` 并同步。

## 6. 排错(GUI 不弹 / 很卡)
| 现象 | 原因 / 办法 |
|---|---|
| 没弹窗 | 确认在 WSL2(WSLg)里跑;`echo $DISPLAY` 应非空 |
| 很卡 / 黑屏 | 容器里是软件渲染,且后台在编译占 CPU → 等编译完再跑更流畅 |
| 报错找不到镜像 | `docker images` 看是否齐;不齐说明还在建 |
