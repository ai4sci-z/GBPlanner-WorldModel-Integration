## 二、ROS 基础

| 词 | ①人话 | ②本项目对应 | ③怎么验证 |
|---|---|---|---|
| ROS1 / ROS2 | 机器人软件的"操作系统",两代互不兼容 | GBPlanner=ROS1(noetic);world-model=ROS2(jazzy) | — |
| node(节点) | 一个干活的程序 | 如 `gbplanner_node`、`thinbridge_ros2` | `rosnode list`/`ros2 node list` |
| topic(话题) | 节点间的广播频道 | 如 `/slam/odom`、`/gbp/trajectory` | `rostopic hz`/rclpy 订阅计数 |
| message(消息) | 频道里流的数据包 | 如 Odometry(位姿)、PointCloud2(点云) | echo 一条看字段 |
| launch | 一键起一组节点的配置 | `wm_planner.launch`(纯 planner 栈) | roslaunch 后 rosnode list |
| TF / frame | 坐标系家谱(map→base_link→雷达) | 桥广播 world→base_link;tf_5 静态 base_link→velodyne | TF 缺失=建图报 transform 错 |
| QoS | ROS2 频道的"服务质量"参数,不匹配就收不到 | B16 的 /tf_static 坑(latched 需 TRANSIENT_LOCAL) | 见 Bug 台账 B16 |
| rclpy / rospy | ROS2 / ROS1 的 Python 客户端库 | 薄桥两端各用一个 | — |
