## 2. Fixed Frame 与 TF 链

- RViz Fixed Frame = `world` ✓(截图与配置一致)。
- **world→map**:恒等改名,由桥实现(thinbridge_ros2_side L116:map→world 只改 frame 字符串,
  不做任何旋转/平移;ROS1 侧 L99 落地 frame=world)——代码级确认;本 run 同刻位姿对比
  单发取证为空(rostopic/ros2 echo 单发在 run 退化期抓空,工具时序问题,非结论)。
- **map→odom→base_link**(ROS2 侧,SLAM/运行时发布):tf2_echo 单发未抓到
  (该 run 150s 即超时退化;历史全绿 run 的 frame_contract 8/8 话题含 /tf 证明链存在)。
- **base_link→lidar3d_frame:TF 不存在(实测确认)**——lidar3d 是净增量传感器,未配 TF
  发布器;**这是设计内**:点云过桥时由桥层重打 frame 与 TF(world→base_link 从 /wm/odom
  广播 + 静态 base_link→velodyne),ROS1 侧 voxblox 不依赖 ROS2 的 lidar3d_frame。

## 4. 地标对照(挂起项 B,最重要)

- SDF 事实(maze_landmarks.md):20×20m,外墙 ±10,右旋螺旋,**墙间距 3m**(x/y 的
  -10/-7/-4/-1 处),入口在东北外墙缺口;世界内另有球形障碍(sphere)与 lipo 盒。
- 实测(墙体高度带 0.3~2.5m,0.2m 桶直方图):外沿 ±8.5(可解释:lidar 量程 10m+中心起飞,
  角落未观测);**墙线峰 x{-3.2,-1.8,-1.0,4.4,5.0,6.4,7.0,8.4} / y{2.2,…,7.0},峰距 0.6~1.0m,
  与 3m 栅距不符**。
- 候选解释(按优先级排查):①**map 相对 world 存在旋转**(SLAM map 系 yaw≠world yaw——与已
  根治的 EKF 参考系家族同源,axis 对齐墙在旋转系下形成密集斜峰)②球形障碍点污染直方图
  ③SLAM yaw 漂移导致墙体涂抹。
- **关闭实验(已定义)**:a) 直方图前先剔除球状聚类;b) 取三堵全长外墙做直线拟合,
  解 map↔world 旋转角 θ;若 θ≈0 则排①;若 θ 显著,评估是否影响演示口径(体素图仍是
  "真实 3D 输入建图"的证据,但"与 Gazebo 逐地标可叠合"须在校正 θ 后宣称)。
