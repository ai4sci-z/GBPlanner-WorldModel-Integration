# launchers/ 一键演示入口(双击即用)

> 桌面有同名文件夹副本《GBPlanner一键演示》。配套讲解:[实操手册](../docs/实跑操作手册_图文版.md) · [RViz界面详解](../docs/体积增益与RViz界面详解.md)。2026-07-04 实测。

| 双击 | 干什么 | 你会看到 |
|---|---|---|
| `1-启动GBPlanner仿真.bat` | 自动开"看门"(防 WSL 空闲关机)+ 启动仿真 | 弹两个黑窗口(**都别关**);约 20-30 秒后 **RViz 弹出** |
| `2-起飞并自主探索.bat` | 无人机起飞并开始自主探索 | 黑窗口打印起飞高度(0.05→1.20)与 success: True;RViz 里三色轴起飞、绿线粉线开始生长 |
| `3-停止仿真.bat` | 关闭仿真容器 | RViz 关闭 |

使用顺序:1 → 等 RViz 出现再等 30 秒 → 2 → 观赏(约 7 分钟自动返航)→ 3。
故障先查实操手册 §5 排查表。
