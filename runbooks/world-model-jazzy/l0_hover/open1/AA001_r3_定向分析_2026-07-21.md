## 3. 最强候选链(候选,非 CONFIRMED)

> **SITL FCU 的 LOCAL_POSITION_NED 输出存在随机时长的慢启动爬升期 → 当爬升慢于
> 新鲜度阈值(1000ms)时 `fcu_local_position_ready` 持续抖动、无法攒足连续 5s 稳定 →
> 60s 等待预算耗尽 → `hover_mission_abort:waiting_for_fcu_external_nav` → 从未 arm →
> (LOG_DISARMED=0)无 BIN。**

一条链同时候选解释三件事:no-BIN 类失败(=从未 arm,非"死得早")、间歇性(爬升时长
随机,非代码差异)、同 commit 成败并存(时序变异)。

- **支持**:①两向桥证据健康,排除 companion→FCU 方向;②帧级全程速率判别(前 40s:
  0.8-2.6 vs 1.75-5Hz),且 FAIL 在 60s 后也收敛=启动期现象而非永久故障;③预算权威值
  与 history 抖动模式自洽;④EKF flags/origin/home 两 run 相同,无 EKF 拒绝证据;
  ⑤SUCCESS 同样存在爬升期只是更快——连续谱而非二元故障。
- **反对/削弱**:①样本 1v1;②511 DENIED 与总请求数差异方向一致但非独立证据;
  ③history 为 40 条滚动窗,SUCCESS 前 15s 细节缺失(帧级已补足此缺口)。
- **UNKNOWN**:①FCU 侧为何慢启动(EKF 内部时序?SITL 调度?interval 生效延迟?)——
  失败臂**无 BIN=FCU 内部盲区**,现有证据不足以再往下钻;②历史 no-BIN 失败
  (205113/210149,eab0cc6 基线)是否同链——可同法回放验证,按冻结纪律仅登记;
  ③ready 连续段精确长度(0.5s 采样粒度限制)。
