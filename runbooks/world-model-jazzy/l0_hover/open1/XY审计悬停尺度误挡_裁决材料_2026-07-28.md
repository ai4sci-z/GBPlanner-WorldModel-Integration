# XY 对齐审计在悬停尺度的间歇误挡 · 负责人裁决材料(2026-07-28)

> 性质:验收门行为修改提案——**未获批准前不改 gate 代码**(放宽验收门须负责人裁决,红线)。
> 背景:OPEN-1 流请求风暴修复(第一批强支持)后,通往 WP307 默认 10/10 的**最后一类阻塞**
> 即本项(近两批 ×10 中各 2/10,全部"飞行 task_success 但被本审计挡")。

## 1. 现象(实测,runs 20260728T061042 / 062651 等)

`hover_xy_alignment_direction_mismatch:external_nav_odom_candidate__*` + `hover_xy_evidence_disagreement`:
gate 在悬停窗口比较各里程计源的 XY 位移方向,candidate(/external_nav/odom_candidate,selector 输出、
scan-reference 修正前)与其余源 cos≈-0.9(≈180°),被 hardGate 挡;而其余五源(含 gazebo 真值)互相
cos≈+0.98~+0.999 完美一致,飞行本身 task_success。

## 2. 取证与两次分类修正(诚实记录)

1. 初判"深层帧一致性/B21 域"→ 2. 再判"B22 活体复现(IMU roll-180→SLAM 翻转)"→
3. **rclpy 可靠反序列化全 bag 取证推翻前两判**:失败 run 全程 `slam_yaw - truth_yaw = +0.0/-0.1/-0.7°`
(**无任何 180° 翻转;B22 假设证伪**);candidate 全程位移方向与 truth 差 0.6°(一致)。

## 3. 根因(定性)

悬停任务无指令性水平运动,窗口内 XY 位移=**漂移,量级 1.4~8.7cm**;gate 的方向比较幅值护栏
`direction_check_ok` 仅要求 ≥0.05m(gate_evaluation.go:1514)——**护栏阈值≈悬停漂移本身量级**。
candidate 流的瞬态(selector hold 释放/scan-reference 窗口 snap)在厘米尺度可主导其窗口位移方向,
与真实漂移方向解耦 → 方向比较被瞬态支配 → 间歇(~2/10)误挡。**审计对"指令性运动"设计合理,
对"纯悬停漂移"不适定。**

## 4. 提案(三选一,请裁决)

| 选项 | 内容 | 利 | 弊 |
|---|---|---|---|
| A(推荐) | 方向比较幅值护栏 0.05m→0.15m(仅 direction 判据;幅值/符号/样本判据不动) | 悬停漂移(<10cm)不再触发不适定比较;指令性运动(>15cm)仍全额审计 | 5-15cm 区间的真方向分叉不再挡(该区间本就噪声主导) |
| B | candidate 源 direction 判据降为 review-only(audit 记录不挡),其余源不变 | 保留全部数据可查 | 若 candidate 真发生帧级方向错误将不挡(有 B21 前科) |
| C | 维持现状 | 最保守 | 10/10 在统计上几乎不可达(~2/10 误挡),WP307 被非缺陷阻塞 |

判据出处:gate_evaluation.go:1514(`leftMag>=0.05 && rightMag>=0.05`)、:1530(`cos<0.50`)。
A 的实现=一行阈值 + 回归测试(悬停漂移场景不挡/指令运动场景照挡);获批后 test-first 施工。
